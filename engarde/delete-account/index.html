계정 삭제 안내

En Garde 앙가르드 (스튜디오 차안, STUDIO CHAAHN) 계정과 데이터를 지우는 방법입니다.

게임 안에서 삭제하기 (권장)

  1. 게임 오른쪽 위 톱니(설정) → 계정 관리 → 계정 삭제
  2. 두 가지 중 고릅니다.
    • 30일 뒤 삭제: 30일 안에 다시 로그인하면 삭제가 취소됩니다.
    • 지금 바로 삭제: 되돌릴 수 없습니다.

친구 목록은 삭제를 신청하는 즉시 지워지며, 삭제를 취소해도 돌아오지 않습니다.

게임 밖에서 요청하기

게임을 삭제했거나 열 수 없다면 contact@studiochaahn.com 으로 아래 내용을 보내 주세요.

  • 제목: 계정 삭제 요청
  • 이름표(이름#숫자, 게임 설정에서 볼 수 있습니다)
  • 마지막으로 플레이한 대략의 날짜와 기기 종류 (본인 확인용)

본인 확인 후 처리하고 결과를 답장드립니다. 친구 목록을 지우려면 삭제 처리 중에 게임에 한 번 로그인해 달라고 안내드릴 수 있습니다.

지워지는 것

  • 플레이어 ID, 로그인 정보, 이름표
  • 진행, 보유 아이템(구매한 아이템 포함), 대회와 랭크 기록
  • 순위표 기록, 친구, 친구 요청, 차단 목록

남는 것

  • 구매와 지급 기록: 법률에 따라 5년 보관 후 삭제
  • 소비자 불만, 분쟁 처리 기록: 법률에 따라 3년 보관 후 삭제
  • 운영 기록(지급, 회수, 제재 이력): 이름을 지우고 번호만 남겨 6개월 보관 후 삭제 (환불과 부정행위 대응)
  • 삭제를 처리했다는 최소 기록(요청, 완료 시각)

광고 사업자(Unity, Google)가 직접 수집한 광고 정보는 스튜디오가 갖고 있지 않습니다. 기기 설정에서 광고 ID 를 삭제하거나 재설정하면 연결이 끊깁니다.

구매한 아이템은 계정과 함께 사라지며 되돌리거나 다른 계정으로 옮길 수 없습니다. 구매 후 7일 안의 쓰지 않은 아이템이 있다면 삭제 전에 먼저 환불을 요청해 주세요.
